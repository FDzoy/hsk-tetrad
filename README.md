# Тетрадь репетитора HSK

Сайт для занятий по учебнику HSK Standard Course (HSK标准教程), уровни 1–4: слова с озвучкой, грамматика по формулам, упражнения, прописи, вопросы для разговора и домашние задания.

**Открыть сайт:** https://fdzoy.github.io/hsk-tetrad/

## Что где работает

- **Эта версия (GitHub Pages)** — открытый курс: уроки, словарь, упражнения, прописи и домашнее задание по ссылке. Вход по аккаунтам здесь пока не подключён.
- **Версия на claude.ai** — то же самое плюс вход через аккаунт Claude, кабинеты учеников, холсты и роли.

## Как устроено

Обычный статический сайт без сборки: `index.html`, скрипты `app.js`, `app2.js`, `app3.js`, `acc.js`, `board.js` и уроки в папке `data/`.

Чтобы открыть у себя, запустите любой статический сервер в этой папке, например:

```
python -m http.server 8000
```
