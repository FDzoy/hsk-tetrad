# Вход через Google и по почте

На GitHub Pages нет своего сервера, поэтому аккаунты и данные учеников хранит **Firebase** — проект **FDzoy4China**. Для одного репетитора и его учеников хватает бесплатного тарифа Spark, банковская карта не нужна.

Ключи проекта уже вписаны в [`firebase-config.js`](firebase-config.js). Они не секретные: их можно хранить в открытом репозитории, чужие данные защищают правила базы.

## Что должно быть включено в консоли Firebase

Откройте <https://console.firebase.google.com> → проект **FDzoy4China**.

1. **Authentication → Sign-in method** — включены **Google** и **Email/Password**. ✅ уже сделано.
2. **Authentication → Settings → Authorized domains** → **Add domain** → `fdzoy.github.io` → **Add**. Без этого вход через Google на сайте выдаёт ошибку.
3. **Databases & Storage → Firestore Database** → **Create database**:
   - режим **Standard**, база `(default)`;
   - регион — европейский, например `eur3 (Europe)`; поменять его потом нельзя;
   - режим правил — **Start in production mode** → **Create**.
4. В той же базе вкладка **Rules**: удалите всё и вставьте содержимое файла `firestore-mine.rules` (в нём уже вписана почта главного администратора) → **Publish**.
   Если этого файла нет, возьмите [`firestore.rules`](firestore.rules) и впишите свою почту вместо `ПОЧТА_АДМИНИСТРАТОРА@gmail.com`.

После этого и публикации сайта (`git push`) на сайте работает кнопка «Войти».

## Как это работает

**Вход.** Кнопка «Войти» справа вверху: через Google или по почте с паролем. Там же регистрация и «Забыли пароль?».

**Анкета.** При первом входе человек указывает имя, возраст и кто он: **ученик** или **родитель ученика**. Пока анкета не заполнена, на сайт дальше не пускает. Администратору и преподавателям анкета не нужна.

**Роли.**

| Роль | Кто получает | Что видит |
|---|---|---|
| Администратор | главный — по почте из правил базы; остальных назначает администратор | всё: уроки, учеников, холсты, страницу «Пользователи» и смену ролей |
| Преподаватель | назначает администратор | «Ученики»: задания, результаты и холсты всех учеников |
| Ученик | сразу после анкеты, если выбран «Ученик» | свой кабинет, задания и холст |
| Родитель | сразу после анкеты, если выбран «Родитель ученика» | «Мой ребёнок»: задания и успехи привязанных детей, только просмотр |

**Страница «Пользователи»** (только для администратора): все зарегистрированные, их возраст, ответ из анкеты и почта. Роль меняется выпадающим списком и применяется сразу, даже если человек сейчас на сайте. У родителя там же кнопка «+ привязать ученика». В анкете родитель пишет имя ребёнка, чтобы было понятно, кого привязать.

**Безопасность.** Сам себе человек может выбрать только «Ученик» или «Родитель», и только один раз. Повысить себя до преподавателя или администратора нельзя: это проверяют правила базы, а не только сайт.

Если главный администратор входит по почте и паролю, а не через Google, сначала нужно подтвердить почту по ссылке из письма и обновить страницу.

Совсем удалить чей-то аккаунт можно в Firebase: **Authentication → Users**.

## Проверить у себя на компьютере

Обычный запуск на `localhost` включает тестовый режим без входа: данные хранятся в браузере. Чтобы проверить настоящий вход через Firebase, откройте адрес с параметром `?fb`, например `http://localhost:8000/?fb`. Адрес `localhost` уже разрешён в Firebase по умолчанию.
